# Clusters de conteúdo: innerplacement.com.br

Data: 09/11/2026. Mercado: pt-BR, Brasil. Sementes: "outplacement executivo" e "transição de carreira para executivos".
Modo análise: mapeamento de páginas existentes, lacunas e links. Nenhum post ou brief foi produzido. Texto novo depende de aprovação dos sócios.

## 1. Conclusão

1. **A sobreposição de SERP não foi medida.** Não há percentuais nem matriz 0-10 neste documento (seção 2). O agrupamento abaixo é editorial, baseado no conteúdo das páginas.
2. **O conteúdo existe, mas não está ligado às páginas que vendem.** Nenhum post liga para as duas páginas de Transition, e nenhuma página de programa liga para posts.
3. **"Outplacement executivo" é a maior lacuna.** Só aparece no corpo de dois posts cujo assunto é outro. Não há post dedicado, e o termo exato não está no título, H1 ou descrição de `/para-sua-empresa/outplacement/`.
4. **A transição tem base própria.** Cinco posts cabem no hub `/para-voce/transicao-e-recolocacao/`, mas nenhum deles liga para ele hoje.
5. **Todas as correções de link da seção 6 usam palavras já publicadas.** Nenhuma exige texto novo nos posts. Os módulos nas páginas de programa exigem decisão dos sócios.
